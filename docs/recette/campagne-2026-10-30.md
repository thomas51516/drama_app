Top défauts par gravité (détail dans `defauts.md`) :

1. **DEF-001 (majeur, backend/web)** — un épisode transcodé `READY` d'une série publiée reste invisible dans l'application tant que l'éditeur n'a pas renseigné une date de publication épisode par épisode (`publishedAt` nul → exclu, `episodeCount = 0`, `/play` → 404). Le flux « upload → publier la série » ne suffit donc pas à mettre un épisode en ligne.
2. DEF-002 (mineur) — `GET /search` exige `q` : pas de recherche par genre seul côté API.
3. DEF-006 (mineur, Android) — une session invitée dont le refresh est refusé est remplacée silencieusement par un nouvel invité (identifiant changé en cours d'utilisation, progression serveur orpheline).
4. DEF-005 (mineur, web) — étape TOTP : code incomplet accepté à la soumission et message générique « Une erreur est survenue (400) ».
5. DEF-003 / DEF-004 (mineurs, backend) — `PUT /progress` accepté sur un épisode verrouillé ; `POST /play` ignore la restriction de territoire appliquée par le catalogue.
