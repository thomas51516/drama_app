=== DEF-008: paramètres non validés (cursor, X-Country) ===
$ curl -s -w "\nHTTP %{http_code}\n" "http://localhost:3000/feed?cursor=garbage" -H "Authorization: Bearer <token>"
{"statusCode":400,"code":"VALIDATION_ERROR","details":{"errors":["cursor is not a valid feed cursor"]}, ...}
HTTP 400
$ curl -s -w "\nHTTP %{http_code}\n" "http://localhost:3000/home" -H "X-Country: ZZZZ"
{"statusCode":400,"code":"VALIDATION_ERROR","details":{"errors":["X-Country must be an ISO 3166-1 alpha-2 country code"]}, ...}
HTTP 400
=> OK : un curseur illisible et un code pays hors ISO 3166-1 alpha-2 sont désormais rejetés explicitement (400
   VALIDATION_ERROR) au lieu d'être silencieusement ignorés. Fermé.
